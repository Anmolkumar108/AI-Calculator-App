# 🚀 AI Calculator App

A modern Python GUI Calculator App built using CustomTkinter.

## Features

- Normal Calculator
- Scientific Calculator
- GST Calculator
- Discount Calculator
- BMI Calculator
- Currency Converter
- Unit Converter
- AI Assistant
- Dark Theme
- Database History
- Voice Assistant

## Technologies Used

- Python
- CustomTkinter
- SQLite3
- Pyttsx3

## Run Project

```bash
python main.py
```
